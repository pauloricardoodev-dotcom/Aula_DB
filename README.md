## 💻 Exemplos

Exemplo de criação de uma tabela

```sql
CREATE TABLE alunos (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100)
);
```

Inserção de dados

```sql
INSERT INTO alunos (id, nome, email)
VALUES (1, 'João', 'joao@email.com');
```

Consulta

```sql
SELECT 
FROM alunos;
```
